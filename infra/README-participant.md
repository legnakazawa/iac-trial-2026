# 参加者向け README

このワークショップでは、**Azure アカウントも GitHub アカウントも不要**です。社内 PC のブラウザだけで VS Code 環境を利用します。

## 事前準備

**不要です。** 以下を主催者から受け取るだけで開始できます。

| 受け取るもの | 例 |
|-------------|-----|
| URL | `http://20.x.x.x:8001` |
| パスワード | 主催者から個別に通知された文字列 |

> 他の席の URL・パスワードは使用しないでください。

---

## 1. 環境に接続する

1. 社内 PC のブラウザ（Chrome / Edge など）を開く
2. 主催者から渡された **URL** にアクセスする
3. パスワード入力画面が表示されたら、通知された **パスワード** を入力する
4. ブラウザ上に VS Code（code-server）が表示されれば成功です

### 接続できない場合

主催者に以下を伝えてください。

- 使用した URL
- 表示されたエラーメッセージ（スクリーンショットがあると助かります）
- 社内プロキシやセキュリティソフトを利用しているか

---

## 2. ワークスペースの確認

VS Code が開いたら、左のエクスプローラーで `/home/coder/workshop`（または `workshop` フォルダ）を確認してください。

次のファイルが含まれています。

| ファイル | 内容 |
|---------|------|
| `main.tf` | 作成する Azure リソースの定義 |
| `variables.tf` | 変数定義 |
| `outputs.tf` | 作成結果の出力定義 |

認証情報は環境にあらかじめ設定されているため、**`az login` は不要**です。

---

## 3. Terraform を実行する

VS Code 下部の **ターミナル** を開き、以下を順に実行します。

```bash
cd ~/workshop
terraform init
terraform plan
terraform apply
```

`terraform apply` では `yes` と入力して確定します。

### 実行結果の確認

```bash
terraform output
```

Storage Account 名などが表示されれば成功です。

### よくあるエラー

| メッセージ | 対処 |
|-----------|------|
| 認証エラー（Authentication failed） | 主催者に連絡（環境側の設定を確認してもらう） |
| ストレージ名の重複 | 主催者に連絡（席の割り当てを確認） |
| `terraform: command not found` | 主催者に連絡（コンテナの再起動が必要な場合あり） |

---

## 4. ハンズオンの流れ（例）

1. `main.tf` を開き、コメントや TODO に従って編集する
2. `terraform plan` で変更内容を確認する
3. 問題なければ `terraform apply` で反映する
4. Azure ポータルは使わなくても作業できます（主催者が確認用に見せる場合を除く）

---

## 5. 終了時

### リソースの削除（指示がある場合）

ターミナルで以下を実行します。

```bash
cd ~/workshop
terraform destroy
```

確認プロンプトでは `yes` と入力します。

### ブラウザ

- タブを閉じるだけで問題ありません
- パスワードは他人に共有しないでください

---

## 禁止・注意事項

- 他の参加者の URL にはアクセスしない
- パスワードや画面に表示される認証情報を SNS・チャットに投稿しない
- ワークショップ用 Azure リソースを個人用途に流用しない
