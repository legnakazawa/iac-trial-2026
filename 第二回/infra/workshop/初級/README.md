# 初級

## ゴール

- `terraform init` / `plan` / `apply` の流れを体験する
- Storage Account と Blob コンテナを共有 RG にデプロイする

## 手順

1. `variables.tf` の `display_name` を自分の名前に変更
2. `terraform init`
3. `terraform plan`
4. `terraform apply`
5. `terraform output` で Storage 名を確認

## 次のステップ

[`中級/`](../中級/) の内容に進み、ネットワークと Private Endpoint を追記します。完成形は [`完成形/`](../完成形/) を参照してください。
